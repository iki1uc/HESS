### 9×9 · 12D · 6 Ebenen · Slide³ · Speed³ · Bonus

UNLINEAR CHESS ist ein nicht‑lineares Schachsystem, das jede Aktion als
geometrische Transformation in einem 12‑dimensionalen Vektorraum interpretiert.
